Política de Privacidad

Simulador Hipotecario Chile

Última actualización: 15 de septiembre de 2026.

1. Independencia

Este sitio es un simulador educativo e independiente. No representa a ningún banco, institución financiera, administradora de fondos de pensiones ni entidad crediticia.

2. No recopilamos datos personales

El simulador no solicita, almacena ni transmite a ningún servidor información personal identificable como:

  • Nombre, RUT, correo electrónico o teléfono.
  • Datos bancarios, de tarjetas de crédito o cuentas.
  • Información tributaria o de patrimonio.

Todos los valores ingresados (sueldo, valor de la propiedad, CAE, etc.) se procesan únicamente en el navegador del usuario.

3. Peticiones de red externas

Para obtener el valor actual de la Unidad de Fomento (UF), el sitio consulta la API pública de findic.cl mediante HTTPS y, si esta no responde, usa como respaldo la API de mindicador.cl. No se envían datos del usuario en estas peticiones.

4. Cálculos locales

Todos los cálculos hipotecarios se ejecutan en el dispositivo del visitante mediante JavaScript. No existe backend ni base de datos que registre las simulaciones.

5. Propósito educativo

Los resultados mostrados son estimaciones aproximadas con fines informativos y educativos. No constituyen una oferta, cotización, pre-aprobación o asesoría financiera. Para contratar un crédito hipotecario real, acude directamente a una institución financiera regulada.

6. Contacto

Sitio creado y mantenido por elclay7. El código fuente está disponible en GitHub.
